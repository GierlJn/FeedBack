# FeedBack
FeedBack is a charity app, that show users the impact their donations make. It further motivates to donate to impactful charities
by implementing gamification elements such as points for donations, achievements and leaderboards.

## Built With

* [Firebase](https://github.com/daltoniam/Starscream) - Database for user management
* [Stripe](https://github.com/stripe/stripe-ios) - For donations
* [ChameleonFramework](https://github.com/sanfreefeng/ChameleonFramework) - Color Framework
* [SVProgressHUD](https://github.com/SVProgressHUD/SVProgressHUD) - Animatons
* [Alamofire](https://github.com/Alamofire/Alamofire)

* [SVProgressHUD](https://app.sogive.org/) - Charity research and impact data
